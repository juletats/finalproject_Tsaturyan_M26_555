# finalproject_Tsaturyan_M26_555

Итоговый проект. Платформа для отслеживания и симуляции торговли валютами.

## 1. Подготовка

### Обзор проекта

**Valuta Trade Hub** - консольное приложение, платформа для отслеживания и симуляции
торговли валютами. Пользователь регистрируется, ведёт портфель кошельков в фиатных и
крипто-валютах, покупает и продаёт валюту по актуальным курсам и получает сводку
стоимости портфеля в выбранной базовой валюте. Данные хранятся в JSON-файлах,
курсы - в локальном кеше `data/rates.json` (позже его наполняет отдельный
Parser Service).

Платформа рассчитана на два сервиса:

* **Core Service** - это приложение: CLI, пользователи, портфели, сделки,
  история операций, работа с курсами.
* **Parser Service** - отдельное приложение-парсер, которое по запросу или
  расписанию получает курсы из публичных API и обновляет `data/rates.json`.
  Пока он не подключён, используется заглушка `utils.build_stub_rates`, а точка
  расширения сосредоточена в `usecases.refresh_rates()`: достаточно заменить
  её тело, формат кеша остаётся прежним.

## 2.1. Модели предметной области

### `User` - пользователь системы

Приватные атрибуты: `_user_id`, `_username`, `_hashed_password`, `_salt`,
`_registration_date`. Пароль нигде не хранится в открытом виде: используется
односторонний псевдо-хеш `sha256(password + salt)`, соль случайна и хранится
рядом.

| Элемент | Назначение |
| --- | --- |
| `User.create(username, password, user_id)` | создаёт пользователя с новой солью и хешем |
| `get_user_info()` | строка с id, именем и датой регистрации (без пароля) |
| `change_password(new_password)` | проверяет длину, перегенерирует соль и хеш |
| `verify_password(password)` | сверяет введённый пароль с сохранённым хешем |
| `user_id`, `registration_date`, `hashed_password`, `salt` | геттеры без setters |
| `username` | геттер + сеттер: имя не может быть пустым |
| `to_dict()` / `from_dict()` | запись для `users.json` |

### `Wallet` - кошелёк одной валюты

Приватные атрибуты: `_currency_code`, `_balance`.

| Элемент | Назначение |
| --- | --- |
| `balance` (property) | геттер; сеттер отклоняет отрицательные значения и нечисловые данные |
| `deposit(amount)` | пополнение, `amount` обязано быть положительным числом |
| `withdraw(amount)` | снятие с проверкой остатка, иначе `InsufficientFundsError` |
| `get_balance_info()` | строка вида `BTC: 0.0500` |
| `currency_code` | геттер без setters, код приводится к верхнему регистру |

### `Portfolio` - все кошельки одного пользователя

Приватные атрибуты: `_user_id`, `_wallets`, `_user`.

| Элемент | Назначение |
| --- | --- |
| `add_currency(currency_code, balance=0.0)` | создаёт кошелёк; код валюты обязан быть уникальным |
| `get_wallet(currency_code)` | возвращает кошелёк или `WalletNotFoundError` |
| `get_total_value(base_currency='USD')` | суммарная стоимость портфеля в базовой валюте по курсам |
| `user` | геттер объекта пользователя, перезапись запрещена (`bind_user` привязывает однократно) |
| `wallets` | геттер возвращает копию словаря, состояние в обход методов не меняется |

## 2.2. Командный интерфейс

CLI живёт в `valutatrade_hub/cli/interface.py` и является единственной точкой
входа пользовательских команд: строка разбирается `shlex`, аргументы проверяются,
вызывается бизнес-логика из `core/usecases.py`, результат печатается.

| Команда | Аргументы | Результат |
| --- | --- | --- |
| `register` | `--username <str> --password <str>` | пользователь в `users.json` + пустой портфель |
| `login` | `--username <str> --password <str>` | сессия текущего запуска |
| `show-portfolio` | `[--base <str>]` | кошельки и итог в базовой валюте (по умолчанию USD) |
| `buy` | `--currency <str> --amount <float>` | кошелёк создаётся автоматически, баланс пополняется |
| `sell` | `--currency <str> --amount <float>` | баланс списывается |
| `get-rate` | `--from <str> --to <str>` | курс пары и обратный курс с меткой времени |
| `help`, `exit` | - | справка, выход |

Пример сессии:

```text
>>> register --username alice --password 1234
Пользователь 'alice' зарегистрирован (id=1). Войдите: login --username alice --password ****
>>> login --username alice --password 1234
Вы вошли как 'alice'
>>> buy --currency BTC --amount 0.05
Покупка выполнена: 0.0500 BTC по курсу 59337.21 USD/BTC
Изменения в портфеле:
- BTC: было 0.0000 → стало 0.0500
Оценочная стоимость покупки: 2,966.86 USD
>>> show-portfolio
Портфель пользователя 'alice' (база: USD):
- BTC: 0.0500  → 2966.86 USD
---------------------------------
ИТОГО: 2,966.86 USD
>>> get-rate --from USD --to BTC
Курс USD→BTC: 0.00001685 (обновлено: 2026-11-08 16:54:06)
Обратный курс BTC→USD: 59337.21
```

Обработанные ошибки (тексты приходят из доменных исключений, CLI печатает их как есть):

| Команда | Ошибка |
| --- | --- |
| `register` | `Имя пользователя 'alice' уже занято`, `Пароль должен быть не короче 4 символов` |
| `login` | `Пользователь 'bob' не найден`, `Неверный пароль` |
| `show-portfolio` | `Сначала выполните login`, `Неизвестная базовая валюта 'ABC'` |
| `buy` | `'amount' должен быть положительным числом`, `Не удалось получить курс для BTC→USD` |
| `sell` | `У вас нет кошелька 'ETH'. Добавьте валюту: она создаётся автоматически при первой покупке.`, `Недостаточно средств: доступно 0.0500 BTC, требуется 0.1000 BTC` |
| `get-rate` | `Курс USD→BTC недоступен. Повторите попытку позже.` |

Дополнительно: сессия живёт в рамках одного запуска, поэтому многошаговые
сценарии (`login` → `buy` → `show-portfolio`) выполняются в интерактивном режиме
(`make run`); режим одной команды удобен для запроса курсов. Покупка и продажа
считаются «оценочно» - USD-кошелёк в сделках не участвует; чтобы включить
расчёты через него, в `usecases.py` нужно поставить `SETTLE_IN_USD = True`.

### Форматы данных

`data/users.json` - массив записей пользователя:

```json
[
  {
    "user_id": 1,
    "username": "alice",
    "hashed_password": "9f86d081...",
    "salt": "d3Bx9K",
    "registration_date": "2026-11-08T16:54:06"
  }
]
```

`data/portfolios.json` - массив портфелей, кошельки ключуются кодом валюты:

```json
[
  {
    "user_id": 1,
    "wallets": {
      "USD": { "balance": 1500.0 },
      "BTC": { "balance": 0.05 }
    }
  }
]
```

`data/rates.json` - кеш курсов: пары вида `EUR_USD` (сколько USD стоит 1 EUR),
отметка времени каждой пары, а также `source` и `last_refresh` для всей таблицы.
Курс считается актуальным `RATES_TTL_SECONDS = 300` секунд; устаревший кеш
обновляется автоматически, курсы без данных дают ошибку `get-rate`. Пары, которых
нет в кеше напрямую (например, `EUR→BTC`), вычисляются через базовую валюту.
